# 🐕 3D Dog Experience

An interactive 3D web experience built with React, React Three Fiber, Three.js, and GSAP.

The project focuses on combining 3D models, custom shader effects, material transitions, mouse interactions, and scroll-based animations to create an immersive web experience.

## 🌐 Live Demo

[View Live Demo](https://suryastack.github.io/3D-Dog/)


## ✨ Features

- 🐕 Interactive 3D GLTF dog model
- 🌿 Interactive 3D branch model
- 🎨 Custom material and shader effects
- 🔄 Smooth material transitions between different themes
- 🖱️ Mouse-based 3D model rotation
- 📜 Scroll-based animations using GSAP ScrollTrigger
- 🎬 Smooth GSAP animations
- 🖼️ Texture and Matcap-based materials
- 📱 Responsive layout
- ⚡ React Three Fiber integration
- 🎯 Interactive DOM and 3D scene interactions

## 🛠️ Tech Stack

- React
- React Three Fiber
- Three.js
- GSAP
- GSAP ScrollTrigger
- Drei
- JavaScript
- Tailwind CSS
- Vite

## 🧠 Concepts Practiced

This project was mainly built to practice:

- Integrating Three.js with React
- Loading and working with GLTF models
- Using `useGLTF`, `useTexture`, and `useAnimations`
- Managing Three.js objects with React refs
- Creating custom shader modifications with `onBeforeCompile`
- Working with GLSL uniforms
- Creating animated material transitions
- Using GSAP with React
- Implementing scroll-driven 3D animations
- Handling mouse interactions with a 3D scene
- Connecting DOM interactions with Three.js objects
